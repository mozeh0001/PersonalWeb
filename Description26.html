USC Marketplace Application

CSCI 201 Final Group Project

A full-stack marketplace application developed as a seven-person team project for USC's CSCI 201 course.


  • Built a full-stack web app simulating an online marketplace with buyer/seller accounts, real-time messaging, and ratings.
  • Implemented secure login and registration using Spring Security Crypto and password encryption.
  • Designed multi-threaded messaging with STOMP/WebSockets for real-time conversations.
  • Used MySQL + data structures including sets, heaps, queues, and maps for listings, ratings, and chats.
  • Collaborated in a seven-person team using GitHub for version control and sprint-based development.
