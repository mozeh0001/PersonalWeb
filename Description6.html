QuestMates

Swift | ARKit | SceneKit | Firebase | GameKit | WeatherStack API


QuestMates is an iOS AR social game inspired by Pokémon GO, Pikmin Bloom, and Roblox. Players can match with others for AR challenges, earn currency, customize avatars, and socialize through Firebase chat rooms.


The app also uses the player's location and WeatherStack API data to dynamically change its environment based on current weather conditions.



The App in Action


  • Saves player coins and avatar customization between sessions.
  • Supports customizable 3D avatars.
  • Uses Game Center matchmaking for multiplayer AR challenges.
  • Updates backgrounds using real-time weather and player location.
  • Uses Firebase Firestore chat rooms for social interaction.
  • Uses responsive layouts for both iPhone and iPad.

Apple Frameworks & Technologies


  • GameKit: Handles Game Center authentication and multiplayer matchmaking for AR challenges.
  • SceneKit: Handles 3D rendering, avatar customization, characters, and environments.
  • ARKit: Provides scene tracking for multiplayer augmented-reality challenges.
  • MapKit: Supports location-based features within the application.
  • SwiftUI: Handles interface layouts and user interaction while integrating UIKit components where needed.
  • CoreLocation: Retrieves the player's geographic location for location and weather-based features.
  • QuartzCore: Provides animation functionality including Core Animation.
  • Firebase Firestore: Handles real-time chat data and social chat rooms.
  • WeatherStack API: Provides current weather data used to dynamically update the app environment.
