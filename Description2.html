Smart Robot For Children

OpenCV | MediaPipe | DeepFace | C++ | Particle IoT | Initial State




An interactive robot designed for children that mimics human movement, displays facial expressions, monitors interaction data, and encourages physical engagement.


  • Uses Particle Argon and servos to mimic human movements.
  • Displays facial expressions through a MicroOLED screen.
  • Uses DeepFace, OpenCV, and MediaPipe for emotion and body detection.
  • Encourages active interaction over passive screen time.
  • Logs user interactions and emotional data for analysis.

Heart Rate Monitoring

  • Monitors real-time BPM to detect possible stress responses.
  • Sends sensor data through the Particle Cloud API.
  • Displays a heart animation for user-friendly feedback.

Facial Recognition & Emotion Display

  • Detects human faces using OpenCV.
  • Analyzes facial emotions using DeepFace.
  • Displays real-time graphical emotions on the OLED screen.

Emotions Displayed on OLED

Body Mimicking & Motion Tracking

  • Uses MediaPipe to track human body movement.
  • Converts tracked poses into robot motion.
  • Calculates servo angles in real time for limb positioning.
  • Allows the robot to mimic actions such as waving, kicking, and posing.

Body Tracking - MediaPipe Diagram

Remote Control & Blynk App

  • Controls the robot remotely through Blynk.
  • Uses sliders for manual joint and pose control.
  • Allows real-time adjustment of robot movement.
  • Supports facial-expression updates on the OLED display.

Blynk Robot Control Interface

Data Tracking & Analytics

  • Tracks how often each detected emotion occurs.
  • Stores interaction patterns and trends.
  • Visualizes behavioral data over time.

Child Mood Over Time

Hardware Components

  • 10 servos for arms, legs, elbows, and hip movement.
  • MicroOLED display for facial expressions.
  • PIR sensor for detecting human presence.
  • Heart-rate sensor for real-time BPM tracking.
  • Particle Argon for connected-device control and cloud communication.
