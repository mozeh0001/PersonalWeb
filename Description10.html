Bridge Breakout

Personal Project | Unity | C# | Blender


Bridge Breakout is a mobile action-adventure game where players use a grappling hook to travel across highways, protect bridges, and stop bandits from destroying the road network.


The game consists of five short levels built around traversal, combat, bridge protection, and increasingly difficult enemy encounters.


I developed the project in Unity and created the gameplay systems, environments, scripts, UI, VFX, and most visual assets.

Mobile Input & Grappling


  • Implemented dual virtual joysticks for player movement and camera control.
  • Created touch-based grappling hook input for traversal across broken highways.
  • Added a crosshair that changes color when an enemy is targeted.
  • Developed bridge-health UI that responds to cars falling or structural damage.
  • Animated the grappling line using a sine-based Line Renderer effect.

Mobile Controls

Visual Effects


  • Used VFX Graph to create water splashes when cars collide with the water.
  • Created fire and explosion effects using Unity particle systems.
  • Used Shader Graph for the water surface.

Water Splash VFX

Level Design


  • Designed the highway layouts and level flow for the game's five levels.
  • Modeled curved roads, freeway structures, buildings, and signage in Blender.
  • Designed spaces around grappling traversal and enemy encounters.

Highway Level Design

Enemy AI & Navigation


  • Built an enemy state machine for switching between patrol, player attacks, road attacks, and bridge-column attacks.
  • Used NavMesh navigation for enemy movement throughout the highway environment.
  • Added NavMesh Links so enemies could jump between separated highway sections.
  • Synchronized jump animations with navigation across bridge gaps.

Optimization & Traffic Systems


  • Created a waypoint system that allows cars to follow highway routes.
  • Implemented object pooling to reuse vehicles rather than repeatedly instantiating and destroying them.
  • Reduced unnecessary garbage collection and runtime allocation during gameplay.
